# 本批最新样例与使用方法

路径根目录：`d:\QT_CppPrograms\DataLab\samples\`

通用步骤：

1. 启动 DataLab。
2. **文件 → 打开 / 导入** 对应 CSV。
3. 按下面菜单和弹窗参数运行分析。
4. 在输出页查看表格、诊断卡片和图形；可再打开 PDF 预览检查排版。

---

## 1. 双因素 ANOVA

| 项目 | 内容 |
|---|---|
| 文件 | `anova_factorial\factorial_2x2.csv` |
| 菜单 | **统计 → 双因素 ANOVA** |
| 响应变量 | `Response` |
| 因子 A | `FactorA` |
| 因子 B | `FactorB` |
| 因子编码 | `reference` |

对照输出：ANOVA 表（Seq SS / Adj SS / DF / MS / F / P）、因子均值、交互均值。

详细说明：`anova_factorial\README.md`

---

## 2. ARIMA 基础预测

| 项目 | 内容 |
|---|---|
| 文件 | `time_series\arima\arima_trend.csv` |
| 菜单 | **统计 → ARIMA 基础预测** |
| 时间列 | `Period` |
| 时间序列值 | `Value` |
| 选模准则 | `aicc` |
| 预测期数 | `4` |

对照输出：候选模型比较（AIC / AICc / BIC）、Forecast / Lower / Upper、拟合预测图。

详细说明：`time_series\arima\README.md`

---

## 3. 回归残差诊断

| 项目 | 内容 |
|---|---|
| 文件 | `regression_diagnostics\regression_diagnostics.csv` |
| 菜单 | **统计 → 线性回归** |
| 变量顺序 | `Response`、`Temperature`、`Pressure` |

对照输出：Durbin-Watson、删除学生化残差、Cook's D、DFITS、三张残差诊断图。

详细说明：`regression_diagnostics\README.md`

---

## 4. 输出排版检查建议

任选上面三个分析结果，重点看：

- 顶部方法参数摘要卡片
- 诊断信息是否按颜色区分
- 表格数值是否右对齐
- 多图是否分卡显示
- PDF 预览是否包含解释区和诊断区
