# DOE 响应分析样例

该闭环用于已经导入工作表的 2 水平因子设计。工作表应包含一个数值响应列，以及每个因子一列；因子值可以是 `-1/1`，也可以使用对话框中填写的低/高水平文本。

## 操作步骤

1. 导入包含响应和因子列的 CSV。
2. 选择 **质量工具 → DOE 响应分析**。
3. 在“响应列”选择测量结果，在“已导入因子列”多选 2 水平因子。
4. 因子列不是 `-1/1` 时，在低/高水平输入框填写对应文本。
5. 查看系数与效应、DOE ANOVA、残差诊断、主效应图和交互作用图。

## 诊断约定

- 空响应会被保留为缺失运行并不参与拟合。
- 缺少因子组合会报告 `missing_doe_runs`；重复组合会报告 `duplicate_doe_runs`。
- 设计矩阵不能提供正的误差自由度，或存在完全共线时，会报告秩亏/自由度错误。
- 响应列、因子列必须属于当前工作表，且至少选择一个因子。

模型形式为编码变量模型：

`Y = b0 + bA*A + bB*B + bAB*A*B + ...`

效应定义为对应系数的两倍。
