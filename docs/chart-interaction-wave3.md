# 图表交互继续检查（第三批，2026-11-11）

本批在第二批之后继续检查来源联动、页面回调和坐标精度。保持现有 MainWindow、OutputWorkspace、AnalysisChartWidget 与 PlotSpec 的分工，不涉及 MES。

## 来源联动

此前图表行选择直接使用当前工作表，反向选择也会更新所有结果页。切换到另一张表、修改值或重排行后，旧结果可能仍选中当前表相同位置的行。

现在新结果保存来源工作表名称和内容指纹；指纹包含表名、来源路径、列名、物理行顺序和单元格原始内容。字段使用长度前缀，缺失的尾部单元格与规范化后的空单元格等价。结果本身的图表仍使用现有物理行索引协议，没有在本批悄悄改成另一套 RowId 协议。

- 图表/结果表到工作表：只有来源指纹匹配才提交行选择，来源不匹配时保留当前工作表选区。
- 工作表到图表：只更新来源匹配的结果页，其他结果清除反向高亮。
- 数据编辑、列名编辑及模型重置使缓存失效，并清除旧高亮。内容指纹在需要核对时计算，普通悬停不计算整表指纹。
- 恢复原表和原始内容后可重新匹配；视图代理排序不改变源数据顺序，仍可联动。
- 来源字段随 OutputPage JSON 保存。旧结果缺少来源信息时不会猜测绑定，显示暂停联动的提示；查看、图内选择、属性编辑和导出仍可使用。
- 图表到工作表的索引校验改为实际数据行数，不接受工作表显示用空白行作为有效源行。

这补齐了第二批说明中“跨工作表及历史数据版本来源隔离”的安全边界。它采用匹配时联动、变化后暂停的策略，没有自动重新映射已经重排的历史数据，也没有自动切换到另一张工作表。

## 页面与坐标

- 显示属性和行联动回调绑定实际页面控件，避免重复结果 ID 写入其他页面；页面移除后，延迟到达的回调不再写入仍打开的页面。
- 标签显示来源及联动状态。关闭页面后刷新标签，析构时先停止访问页面和来源缓存的自身回调。
- 坐标缩放取消绝对 `1e-12` 最小跨度。倍率为 1 保持原范围；极小数值可按比例缩放。缩放或平移若导致非有限数、区间塌缩，则保留原视图。
- 箱线图和小提琴图的范围留白不再强制至少 `1e-6`，避免小单位数据被压成一条线。

## 验证与验收

新增并登记 `tests/analysis_source_binding_test.cpp`，包含 9 个回归用例：来源/行序/内容变化、字段边界与补空、JSON 与旧结果、双向联动隔离、重复 ID 与关闭回调、极小范围缩放、聚合图范围和无效导航保护。

本批启用新的独立审查 agent，进行静态代码检查。按用户要求，**没有执行命令行构建、自动化测试或 GUI 运行**；这些用例尚未执行。

请在 Qt Creator 验收：

1. 分析工作表 A 后切换 B，点击旧图和结果表，确认不会改变 B 的选区；回到 A 后恢复联动。
2. 改值、改列名、重排行，确认旧结果暂停联动；恢复原内容后再操作，确认匹配；代理排序后源行仍正确。
3. 保存并重新打开新项目，确认来源匹配；打开旧项目，确认提示缺少来源且不会猜测联动。
4. 关闭前面的输出页后编辑后面的图表，检查属性写回、来源标签和页面退出行为。
5. 用 `1e-15` / `1e-18` 级数据检查散点、箱线、小提琴图的范围、命中、Ctrl 缩放与导出；结合第二批清单继续做多 DPI 验收。

结果来源匹配保护不等于全部算法来源映射已经逐项实测。Generic 派生系列、各算法提供的子组成员映射，以及大数据性能仍需单独验收。
