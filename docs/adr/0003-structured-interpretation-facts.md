# ADR 0003：解释层使用结构化事实

- 状态：已接受
- 日期：2026-08-17

## 决策

分析结果通过 `OutputPage::facts` 提供过程能力、控制图、MSA、可靠性、预测、功效、Pareto 和回归的结构化事实。`InterpretationService` 优先消费这些事实，表格文字只作为旧项目文件的兼容回退。

能力结论必须引用 `assumption_status`；回归不得只根据 R² 或残差 AD p 值宣称模型合格。解释层不自动删除离群点，也不把量具 ndc 或 Kappa 直接写成通过。

解释逻辑不再把格式化表头作为生产契约。表格可以调整语言、顺序和展示格式，而不改变统计结论。
