# ADR 0006：第一阶段正式声明简体中文单语

- 状态：部分取代（见 [ADR 0009](0009-report-bilingual-locale-separation.md)）
- 日期：2026-08-17
- 修订：2026-08-21

## 决策

当前版本面向中文质量工程场景，**界面默认**为简体中文。

自 2026-08-21 起：

- UI 默认语言策略仍按本 ADR；
- **报告语言**允许 zh-CN / en-US，并由 ADR 0009 约束：稳定文本 ID、与 UI/系统 locale 分离、缺失翻译诊断。

项目不再把“完全不做翻译管线”作为硬约束；空壳 `.qm` 应逐步被真实 catalog / `.ts` 资源替代。
