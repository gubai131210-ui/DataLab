# 图表交互修正（第二批，2026-11-11）

本批延续 ChartModel → ChartPlotContext → ChartRenderer，以及 AnalysisChartWidget / GraphPropertiesPanel 的现有框架。MES 不在修改范围内。

## 已实现的修正

- 绘制、命中、框选与导航共用坐标上下文。概率图保持 8% 留白；气泡、分组柱、箱线、区间、ECDF、平行坐标、等高线与曲面响应自定义范围和缩放、平移。
- 新增独立的交互几何实现，按真实柱体、箱体、区间线、气泡半径、扇区、网格与平行坐标线段命中。超出绘图区、矩阵间隔和远离图元的空白不再按横坐标误选。
- 矩阵观察点携带所在行列身份；网格可显示部分露出的首行/首列；矩阵缩小后保留最小单元格，避免内部绘图区变成负数。鼠标命中先筛选所在单元格；高亮复用原采样绘制流程。
- 多序列命中携带系列下标和局部点序号；实际观测与预测/拟合点分开解析。没有可靠源行映射时，不再虚构从 0 开始的行号。已存在的空成员列表具有权威性，不回退到另一行。
- 工作表反向选择包含 Actual 系列的正确偏移；直方图缺少成员列表时，只有原始数值与源行一一对应才能按箱边界推导成员，最后一箱包含右端点。
- 鼠标释放后才提交选择；Ctrl 点击切换选择；空白点击清除；Shift 框选缩放；中键或空格拖动平移；Ctrl 滚轮以指针位置缩放；普通滚轮继续交给结果页面滚动。
- 悬停仅在目标/提示内容改变时重新计时，不随小幅鼠标移动不断重置。离开、失焦、隐藏和 Escape 清理临时状态。悬停不再改变属性面板的编辑对象。
- 关闭右键菜单不会误开编辑面板。系列编辑使用稳定下标，允许重名；控制线按完整对象路径匹配，避免同名 CL 系列干扰。
- 图表到表格使用一次批量选区更新和业务重入保护，保留 Qt 表格通知与图表键盘焦点，避免反向回调覆盖预测点或重复系列的选择。
- 缩放和平移使用轻量撤销记录；导航状态经过 PlotSpec / JSON 保存，平移带参考绘图区尺寸，在窗口变化和导出时按比例还原。旧 JSON 缺少这些字段时使用默认视图。
- 保留控制图旧规则标记、Sigma Z 和信号方向提示；修正 Cross 点型在无画笔状态下不可见的问题；属性编辑保留未改动轴界限的原始精度，避免改变标题时截断极小范围或时间戳。
- 曲面投影共用安全的顶点读取，跳过非有限值和缺失顶点，避免不齐整矩阵越界。

## Qt Creator 验收重点

1. 直方图、柱图、箱线图、区间图：点击图元与同一横坐标的空白，框选局部与跨多个图元，核对高亮及源行。
2. 概率图、气泡图、时间序列与多序列图：连续 Ctrl 滚轮、平移、Shift 框选缩放、撤销/重做；核对光标附近数据、高亮、提示及轴范围。
3. 平行坐标、矩阵、热力图、等高线、曲面：在线段中点、网格边界和部分可见单元格操作；检查缩小、大数据、多列与缺失值场景。
4. 拖动期间不切换到工作表；释放后联动；Ctrl 取消已选点；预测点不选中原始数据行；普通滚轮仍可滚动结果。
5. 右键后按 Escape、移出图表、空格平移中失焦、编辑重名系列与 CL 同名系列；检查状态恢复。
6. 修改极小轴范围图/时间轴图的标题，核对范围未被改写；保存重开、PNG/PDF 导出，并检查 100% / 150% / 200% DPI。

## 仍需单独完成的边界

- 历史结果与工作表之间尚缺可靠的版本/来源绑定：切换工作表、重排或替换源数据后，旧结果的源行索引可能失效。本批修正图元到已提供源行的解析，未宣称完成跨工作表及历史数据版本的来源隔离。
- 部分算法生成的 Generic 系列没有独立源行映射；不把这类拟合/派生坐标猜测为原始观测。
- 点型以外的按线段悬停、本地大数据性能、多 DPI 和实际导出仍需运行验收；未给出性能或内存泄漏已经通过实测的结论。
