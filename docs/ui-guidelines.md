# DataLab UI 视觉规范

## 视觉层级

- 应用背景使用浅灰蓝色，内容面板使用白色。
- 导航区使用浅蓝灰色，当前项使用浅青绿色强调。
- 错误、警告和成功状态分别使用浅红、浅琥珀和浅绿色背景。
- 正文优先使用 Qt 默认字体，避免依赖不存在的中文字体。

## 间距与尺寸

- 主窗口建议初始尺寸为 `1440 × 900`，最小尺寸不低于 `1080 × 680`。
- Dock 宽度建议在 `220–300 px`。
- 工具栏图标统一为 `20 × 20 px`。
- 表格行高建议 `26 px`，表头高度建议不低于 `34 px`。
- 面板内部使用 `12–16 px` 内边距。

## SVG 图标

- 使用 `24 × 24` 的 `viewBox`。
- 使用线性图标，默认线宽约 `1.8`，圆角端点和连接点。
- 图标使用 `currentColor`，颜色由 Qt 样式或 QAction 状态控制。
- 图标通过 `:/icons/...` 资源路径加载，不使用工作目录相对路径。

## 业务安全

视觉层改动不得修改：

- QAction 的 object name 和命令 ID；
- `OutputWorkspace::pages_` 与 Tab 的索引关系；
- `WorksheetView` 的选择、编辑、复制、粘贴和撤销逻辑；
- 图表的行选择、缩放、拖拽和命中测试；
- 分析服务、统计领域模块和数据导入规则。

## 图表交互约定

- 图表属性编辑只能从图表绘图区的右键菜单进入；左键双击不打开属性页面。
- 左键单击用于命中点或图形对象，拖拽用于框选，按住空格或使用中键用于平移，Ctrl+滚轮用于缩放。
- 可命中的对象必须提供悬停提示；提示至少包含对象类别、坐标/数值，以及适用时的原始行、标签或分组。
- 直方图、箱线图、热图和饼图显示柱、箱体、单元格或扇区级提示，不将汇总图形伪装成单个观测点。
- 图表在 1080×680、1440×900 以及 125%/150% DPI 下不得出现属性控件遮挡；属性系列表允许横向滚动。
- 图表右键进入编辑模式后，属性面板固定在图表右侧；浏览模式不显示面板，不得覆盖图表。
- 属性面板按当前图元显示适用属性，底部操作区固定，标题、坐标轴、网格和控制线等内容在面板内部滚动。
- XBAR 风格交互要求悬停 tooltip 延迟出现并避开当前点，点选高亮且与原始工作表行联动；控制线、数据区和空白区使用不同的右键编辑对象。
