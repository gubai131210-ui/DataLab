# 数据分析与结果工作区：第一批实施说明

日期：2026-11-11。对应 [审查报告](research/analytics-product-audit-2026-11-11.md)。

本批沿用现有 domain / application / reporting / ui 分层，以及 AnalysisService、OutputPage、PageRenderOptions、OutputWorkspace、ChartPlotContext。没有改动 MES 请求、业务处理或现有分析命令 ID。

## 已实施，待用户构建与运行验收

- F01：交互结果默认进入图表，统计结果、解读与诊断、方法与参数分别查看。统计结果按表选择、按需创建，长表在视口内滚动。无图分析默认进入统计结果。错误优先的摘要始终位于内容导航上方，支持换行与查看完整详情。
- F02：主界面提供“数据准备 / 分析工作台”，分析模式以结果为主，工作表可展开，右侧上下文默认收起。新建、导入、打开已有项目和项目树导航同步切换模式；图表行选择会展开工作表。
- F03/F04：t 分位数自适应括界，df=1 使用稳定 Cauchy 小尾形式；一般小尾避免平方溢出和 x 下溢；VIF 使用中心化平方和。相关 t、Z、回归和预期 PPM 路径改用小尾计算，降低接近 1 的概率相减造成的精度丢失。
- F05：工作表初始化/替换与单元格编辑、清空、删列、改列名统一维护契约，粘贴和撤销重做经整表入口更新状态。已有 RowId 保留，新增行分配新 ID；单列编辑只重新分类对应列。
- F09：SPC 第 2 条判异规则达到 9 点时记录窗口，后续只记录新增点，不重复保存整个前缀；阶段边界首点也正确进入新段。
- F10：时间字符串完整匹配与日期合法性验证，支持日期、空格/T 分隔时间、秒的小数、Z 与显式时区偏移；不再把 ISO 时间静默解析为零点。
- F11/F12：时间序列点、线、刻度及面积图复用共同坐标上下文；面积图自动范围包含零基线；框选缩放和选取也使用共同坐标与真实 X 值。散点观测值应用可见性、颜色、点型、大小和透明度，隐藏点不再被命中。
- F13/F14：图形属性刷新不覆盖编辑会话基线，“撤销本次编辑”保留进入编辑前的状态；结果表数值排序独立于显示文本。

交互内容的折叠、页签和长表视口限制只作用于工作区。报告预览仍使用非交互的完整内容路径，既有 PDF 装配与导出流程继续接收全部 OutputPage 数据，不根据当前页签删减结果。

## Qt Creator 中建议的验收顺序

1. 构建程序与两套新增测试；按项目既有 Qt Test 方式运行测试。
2. 导入带缺失格的数据，填值、粘贴、清空、撤销和重做，确认显示值、缺失状态和有效 N 一致。
3. 运行带 1000 行以上逐观测结果的分析，确认首屏为图表，统计表切换和内部滚动正常，全量复制/导出未少行。
4. 在“数据准备 / 分析工作台”之间切换；新建、重新导入、打开含结果的项目、点击项目树分析和工作表，确认能看到对应内容。
5. 调整时间序列/面积图坐标、缩放和平移；核对点线、刻度、Shift 框选缩放与原始行选择。设置散点样式并隐藏观测值，确认命中与画面一致。
6. 图形编辑后执行“撤销本次编辑”，比较屏幕、复制图片、保存重开与 PDF。
7. 在 1080×680、1440×900 和 125%/150% DPI 下检查长中文标题、告警、双图、统计表和属性面板。
