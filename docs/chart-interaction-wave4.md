# 图表绘制与交互检查（第四批，2026-11-12）

本批继续沿现有 ChartModel、ChartPlotContext、ChartRenderer 和交互几何实现修正。统计计算公式、分析样本和 MES 均不在本批改动范围内。

## 降采样与缺失区间

- 降采样先筛选成对有限的 X/Y，避免首个 NaN/Inf 污染范围或产生非有限数到桶下标的转换。
- 点图优先按实际横、纵轴窗口做二维网格取样，并保留可见极值；再按剩余预算补充边缘标记。大量画外点不能挤掉真正可见的点，同 X 的纵向分布也不再被压成仅几个端点。曲线按当前 X 窗口取样，并保留跨视图边界的相邻点，避免缩放到局部后仍使用整批采样而丢失细节。
- 折线和面积填充检查原始模型索引之间的有限性，不能把降采样跳过的 NaN/Inf 当作连续观测。置信带也按连续有效区间分别填充。
- 合并选中/悬停点时使用排序去重，避免对每个选中点反复搜索采样集合；采样候选的去重也不再扫描整个结果集合。

这部分针对图表模型中保留的非有限断点；算法层已经删除的观测、`connect_missing` 配置及各算法的装配方式仍由原分析逻辑负责。本批没有重新计算或改写原始数值。

## 多序列与透明度

多变量时间序列同时保存实际系列和供源行联动使用的拼接基础数组。把拼接数组再画成曲线，会在不同变量之间产生额外斜线，也可能遮盖系列颜色和隐藏状态。

- 新增共用系列契约：只有 Generic/Actual 系列与基础数组按顺序逐个 XY 精确一致时，才识别为镜像数据；计数相同或近似相等均不够。拟合、预测等明确派生角色不会触发镜像判断。
- 镜像基础数组不重复绘制、不额外参与范围或命中；实际系列的行选择按原拼接偏移解析，并同步支持工作表反向高亮。
- 独立主序列存在拟合/预测辅助线时仍可绘制。拟合/预测恰好重合时，等距离命中优先保留真实观测的源行联动。
- 透明度规则由绘制、范围、命中和框选共用；完全透明系列不能继续命中或扩大自动范围。直接由系列绘制的线、点、置信带和密度填充使用对应透明度。
- Ctrl 取消同源标记时先筛选反向候选，保留成员列表的权威性，避免每个已选点都触发全数组镜像检查。

## 边缘分布图

- 散点区域、顶部 X 直方图和右侧 Y 直方图使用共用布局；两侧柱体的位置经过散点图的同一个 mapper，因此跟随自定义范围、缩放和平移。
- 移除旧直方图比例中的绝对 `1e-12` 下限，使小单位数据也能正确占据显示范围。
- 仅绘制边界和计数都存在的箱，跳过非有限值及无效边界，避免计数多于边界时越界。
- 不再为每次绘制复制整份 ChartModel；标题通过绘制选项控制。原直方图频数保持不变，缩放只改变可见图形。
