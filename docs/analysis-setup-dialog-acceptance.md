## 中文路径 Qt Creator 手工验收

请在 `D:/QT_CppPrograms/DataLab` 的 Qt Creator Debug 配置中运行：

- [ ] 导入中文路径 CSV，打开任意统计分析，确认列名和数值/分类/时间类型标签正常。
- [ ] 在列选择面板中搜索列，执行“添加到角色”和“移除选中列”，确认不会重复添加。
- [ ] 不选择必需列直接点击“运行分析”，确认弹窗不关闭且错误字段获得红色边框。
- [ ] 输入非法数值、超出范围的置信水平，确认可在原弹窗修改后重新提交。
- [ ] 打开“高级选项”，确认历史中心线与历史 Sigma 的依赖启用状态正确。
- [ ] 点击“重置默认值”，确认数字控件、枚举控件和文本控件恢复命令默认值。
- [ ] 将窗口缩窄，确认右侧参数区可滚动，底部“重置默认值/取消/运行分析”保持可见。
- [ ] 完成一次分析，确认原有输出页、行选择、图形交互和报告输出不受影响。

Qt Creator 的手工项目运行依赖本机 Qt 插件和字体环境，自动化测试不能替代上述中文路径验收。
